# DonaAhora

Aplicación web desarrollada en C# para la gestión y coordinación de donaciones de sangre. Permite administrar donantes, solicitudes y usuarios mediante diferentes roles.

---

## Tecnologías

- C#
- .NET 8
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML
- CSS
- JavaScript
- Visual Studio

---

## Arquitectura

El proyecto utiliza el patrón **MVC (Model-View-Controller)**:

- **Models:** Entidades y modelos del sistema.
- **Views:** Interfaz gráfica mediante Razor, HTML y CSS.
- **Controllers:** Control de la lógica y solicitudes.
- **Data:** Conexión y acceso a la base de datos.
- **Services:** Servicios auxiliares de la aplicación.

---

## Funcionalidades

- Registro e inicio de sesión.
- Gestión de usuarios y roles.
- Registro de donantes.
- Gestión de solicitudes de sangre.
- Búsqueda por tipo de sangre y ciudad.
- Registro de interés en solicitudes.
- Control de acceso según el rol.
- Conexión con SQL Server mediante Entity Framework Core.

---

## Base de Datos

Base de datos desarrollada en **SQL Server** para almacenar usuarios, donantes, solicitudes e intereses de donación.
